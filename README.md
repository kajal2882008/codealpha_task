# codealpha_task
Project 1: Sudoku Solver
Description
The Sudoku Solver is a console-based application that solves a standard 9×9 Sudoku puzzle using the Backtracking Algorithm.
Features
Displays the original Sudoku puzzle.
Solves the puzzle using recursion and backtracking.
Checks row, column, and 3×3 subgrid constraints.
Displays the completed Sudoku grid.
Concepts Used
Functions
Arrays
Recursion
Backtracking
Conditional Statements
Loops
Project 2: CGPA Calculator
Description
The CGPA Calculator calculates the Semester GPA and displays the Overall CGPA based on the grades and credit hours entered by the user.
Features
Accepts multiple course details.
Calculates total credits.
Calculates total grade points.
Computes Semester GPA.
Displays Overall CGPA.
Shows all entered course details.
Concepts Used
Vectors
Loops
User Input/Output
Arithmetic Operations
Formatted Output (iomanip)
